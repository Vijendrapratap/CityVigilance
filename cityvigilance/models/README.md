# Local detector weights

`yolov8n.onnx` is downloaded on first use into this folder. It is not committed.

The file is Ultralytics YOLOv8n, trained on COCO, and published under AGPL-3.0. It counts people, bicycles, cars, motorcycles, buses, and trucks. It does not classify weapons or crashes. Inference runs on the CPU of the machine that starts `python -m cityvigilance.server`.
